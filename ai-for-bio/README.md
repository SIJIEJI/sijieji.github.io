# AI for Bio

Proposed course design by Sijie Ji. Version: November 1, 2026.

- [Course website](https://sijieji.github.io/ai-for-bio/)
- [Complete syllabus](syllabus.md)

The course connects machine-learning foundations, scientific debugging, biology-inspired computation and AI for biological discovery. It includes a 14-week schedule, four laboratory briefs, a staged Biology-to-AI capstone, assessment rubrics, preparation and teaching policies.

This is a proposed curriculum, not an announced institutional offering. Slides, assignment starter notebooks, solutions and recordings are not included in this release.

## Website

`index.html` is a self-contained static page with responsive styles, accessible native disclosure controls, module filters and a print layout. It requires no build process or third-party runtime. Publish this directory through the existing GitHub Pages site. `syllabus.md` is the downloadable text version. External readings and datasets are linked, not redistributed.
